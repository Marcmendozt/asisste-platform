# Legacy WCF Backend

Esta carpeta conserva el backend WCF/ASMX histórico separado del legado móvil.

## Uso

- referencia de contratos antiguos
- contraste de comportamiento técnico durante la migración a `Asisste.API`
- consulta puntual de reglas o estructuras de integración heredadas

## Regla

No debe considerarse código activo ni base para una migración directa. Solo sirve como referencia para reconstruir endpoints modernos.
